# Arun Veluri — From Systems to AI

A premium editorial/technical portfolio built with Next.js, React, TypeScript and Framer Motion.

## Requirements

- Node.js 20.9+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Main files

- `app/page.tsx` — homepage content and interactive sections
- `app/globals.css` — visual system and responsive styling
- `app/layout.tsx` — metadata and root layout

## Notes

The portfolio intentionally distinguishes between engineering history, forks, adaptations and experiments. Verify/update public GitHub statistics before publishing them as live numbers.
